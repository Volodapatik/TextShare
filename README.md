# TextShare

Швидка P2P передача тексту між пристроями.

**Жива версія:** https://volodapatik.github.io/TextShare/

## Як користуватися

1. На одному пристрої натисни **Створити кімнату**
2. На іншому введи код (або відскануй QR)
3. Пиши / вставляй текст і надсилай
4. На іншому боці — кнопка **Копіювати**

Без акаунтів. Текст іде напряму між пристроями.
